# SuperFW font renderer and font packs (from GBAWriter)

Taken from GBAWriter (https://github.com/Xinon232/gbawriter, commit
`30ae9561e601f4b145ddfe46a0dc56a7448078ac`) and used by the gbavocab build:

- `src/utf_util.*`, `src/compiler.h`, `src/fonts/font_render.*`, `src/fonts/hangul.h`,
  `src/fonts/font_embed.h`: SuperFW by David Guillen Fandos, GPL-3.0-or-later
  (notices kept in each file).
- `res/fonts.pack`, `res/reader-symbols.pack`: the SuperFW font packs with UNSCII by
  Viznut and GNU Unifont glyphs, GPL-2.0-or-later with the GNU font embedding
  exception (`../gba-free-fonts-licenses/Unscii.txt`).
